# B.E. Lab Manuals

Official lab manuals for Final Year (B.E.) laboratory coursework.

## Available Manuals
- **[DMV_Lab_Manual.pdf](DMV_Lab_Manual.pdf)**: Data Mining and Visualization Lab Manual with syllabus, experiment objectives, theory, and sample outputs.
- **[ML_Lab_Manual.pdf](ML_Lab_Manual.pdf)**: Machine Learning Lab Manual with experiment objectives, datasets, algorithm descriptions, and outputs.

Each subject folder in the repository also contains its dedicated lab manual and viva question sets.
