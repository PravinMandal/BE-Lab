# Machine Learning (ML) Practicals

Complete set of machine learning experiments, implementations, datasets, Jupyter Notebooks, and submission PDFs.

## Experiments

| Experiment | Title | Description | Dataset | Folder |
| :--- | :--- | :--- | :--- | :--- |
| **Exp 1** | PCA on Wine Dataset | Dimensionality reduction using Principal Component Analysis on 13 chemical features; 2D visualization of wine classes. | `Wine.csv` | [Exp1_PCA_Wine](Exp1_PCA_Wine/) |
| **Exp 2** | Uber Fare Prediction | Linear, Ridge, and Lasso Regression modeling to predict taxi fares; feature evaluation using RMSE and R-squared. | `uber.csv` | [Exp2_Uber_Fare_Regression](Exp2_Uber_Fare_Regression/) |
| **Exp 3** | SVM Classification on Digits | Support Vector Machine (Linear and RBF kernels) for 8x8 handwritten digit classification. | `digits.csv` | [Exp3_SVM_Digits](Exp3_SVM_Digits/) |
| **Exp 4** | K-Means Clustering on Iris | Unsupervised clustering, optimal k selection using the Elbow method, silhouette score analysis, and cluster plotting. | `iris.csv` | [Exp4_KMeans_Iris](Exp4_KMeans_Iris/) |
| **Exp 5** | Random Forest for Car Safety | Ensemble learning with Random Forest Classifier, hyperparameter tuning, feature importance ranking, and evaluation. | `car.csv` | [Exp5_Random_Forest_Car](Exp5_Random_Forest_Car/) |
| **Exp 6** | Maze Exploration with Q-Learning | Reinforcement learning agent learning optimal paths in a discrete grid world using temporal-difference Q-learning. | Synthetic | [Exp6_Maze_QLearning](Exp6_Maze_QLearning/) |
| **Exp 6B** | Taxi RL Problem with Q-Learning | OpenAI Gym Taxi-v3 problem solved using tabular Q-learning; evaluation of cumulative reward and convergence. | Environment | [Exp6B_Taxi_RL](Exp6B_Taxi_RL/) |
| **Exp 7** | Emotion Detection from Text | Text sentiment and emotion classification using TF-IDF vectorization and Multinomial Naive Bayes / Logistic Regression. | `emotion.csv` | [Exp7_Emotion_Detection](Exp7_Emotion_Detection/) |
