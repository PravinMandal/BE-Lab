# Data Mining and Visualization (DMV) Practicals

Comprehensive collection of experiments, datasets, Python scripts, Jupyter Notebooks, generated visualizations, and compiled report PDFs for the Data Mining and Visualization laboratory coursework.

## Experiments

| Experiment | Title | Description | Folder |
| :--- | :--- | :--- | :--- |
| **Exp 1** | Data Loading, Storage & File Formats | Load sales data from CSV, Excel, and JSON; clean duplicates and nulls; compute statistics and plots. | [Exp1_Data_Loading_Formats](Exp1_Data_Loading_Formats/) |
| **Exp 2** | Weather Data via Web API | Fetch 7-day hourly weather data using Open-Meteo REST API, clean anomalies, compute correlation matrix, and plot temperature trends. | [Exp2_Weather_API](Exp2_Weather_API/) |
| **Exp 3** | Data Cleaning on Churn Dataset | Identify missing values, detect outliers with IQR, standardize numeric features, and encode categorical variables. | [Exp3_Data_Cleaning_Churn](Exp3_Data_Cleaning_Churn/) |
| **Exp 4** | Data Wrangling on Real Estate Dataset | Grouping, aggregation, pivot tables, multi-indexing, and neighborhood price distributions. | [Exp4_Data_Wrangling_RealEstate](Exp4_Data_Wrangling_RealEstate/) |
| **Exp 5** | AQI Visualization with Matplotlib & Seaborn | Multi-line trends, weekly bar charts, scatter correlations (PM2.5 vs PM10), box plots, and subplots. | [Exp5_Matplotlib_AQI](Exp5_Matplotlib_AQI/) |
| **Exp 6** | Retail Aggregation & Group Operations | Monthly trends, region sales pie chart, region-wise category sales stacked bar, and summary tables. | [Exp6_Aggregation_Retail](Exp6_Aggregation_Retail/) |
| **Exp 7** | Time Series Analysis on Stock Data | Moving averages (7-day and 30-day), seasonal decomposition, autocorrelation, and ARIMA forecasting. | [Exp7_Time_Series_Stock](Exp7_Time_Series_Stock/) |
