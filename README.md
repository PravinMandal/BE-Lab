# B.E. Laboratory Coursework (BE-Lab)

This repository contains all practical coursework, source code, simulation diagrams, datasets, visual outputs, lab manuals, viva preparation guides, and compiled report PDFs for final-year Bachelor of Engineering (B.E.).

---

## Subjects & Lab Directories

### 1. [Data Mining and Visualization (DMV)](DMV/)
- **Experiments**:
  - `Exp1_Data_Loading_Formats`: Multi-format sales data loading, cleaning, and statistics
  - `Exp2_Weather_API`: Open-Meteo REST API weather data extraction, anomaly cleaning, and correlation
  - `Exp3_Data_Cleaning_Churn`: Customer churn data cleaning, outlier handling (IQR), standardization, and encoding
  - `Exp4_Data_Wrangling_RealEstate`: Grouping, pivot tables, multi-indexing, and neighborhood price distributions
  - `Exp5_Matplotlib_AQI`: Multi-line plots, weekly bar charts, AQI correlation scatter, and box plots
  - `Exp6_Aggregation_Retail`: Monthly trends, regional sales pie charts, and stacked category bar charts
  - `Exp7_Time_Series_Stock`: Moving averages, seasonal decomposition, autocorrelation, and ARIMA forecasting
- **Resources**:
  - [DMV Viva Questions & Answers (Markdown)](DMV/DMV_Questions_Answers.md) / [PDF](DMV/DMV_Questions_Answers.pdf)
  - [DMV Lab Manual (PDF)](DMV/DMV_Lab_Manual.pdf)
  - [Compiled Experiment PDFs](DMV/PDFs/)

---

### 2. [Machine Learning (ML)](ML/)
- **Experiments**:
  - `Exp1_PCA_Wine`: Dimensionality reduction using PCA on Wine dataset (13 to 2 features)
  - `Exp2_Uber_Fare_Regression`: Fare prediction comparing Linear, Ridge, and Lasso Regression
  - `Exp3_SVM_Digits`: 8x8 handwritten digit classification using Linear and RBF Support Vector Machines
  - `Exp4_KMeans_Iris`: Unsupervised clustering on Iris flower dataset with Elbow method analysis
  - `Exp5_Random_Forest_Car`: Ensemble classification on Car safety evaluation dataset with feature importance
  - `Exp6_Maze_QLearning`: Grid-world maze navigation using tabular Q-learning
  - `Exp6B_Taxi_RL`: Gym Taxi-v3 reinforcement learning problem using Q-learning
  - `Exp7_Emotion_Detection`: NLP emotion classification using TF-IDF and Naive Bayes / Logistic Regression
- **Resources**:
  - [ML Viva Questions & Answers (Markdown)](ML/ML_Questions_Answers.md) / [PDF](ML/ML_Questions_Answers.pdf)
  - [ML Lab Manual (PDF)](ML/ML_Lab_Manual.pdf)
  - [Compiled Experiment PDFs](ML/PDFs/)

---

### 3. [Industrial Internet of Things (IIOT)](IIOT/)
- **Experiments**:
  - `exp1_potentiometer_alert`: ESP32 potentiometer voltage threshold warning alert with Wokwi diagram
  - `exp2_pir_sensor_uno`: Arduino Uno PIR motion sensor with LED and Serial monitoring
  - `practical3_button_led`: ESP32 pushbutton input and LED switching control
  - `practical4_thingspeak_potentiometer`: ESP32 IoT telemetry uploading potentiometer readings to ThingSpeak cloud
  - `practical5_dht11`: ESP32 DHT11 temperature and humidity sensing with Adafruit library
